# 윷판 승부 v3.8 — 서버 물리 판정 실험판

이번 버전은 기존의 `서버 무작위 판정 → 클라이언트에서 물리 연출 → 윷을 가운데로 모으며 방향을 맞춤` 방식을 교체합니다.

## 작동 방식

1. 버튼을 놓으면 **서버**에서 Cannon-ES로 네 개의 윷을 실제로 투척·충돌·회전·착지시킵니다.
2. 윷의 최종 위치 및 면 방향을 판독해 도/개/걸/윷/모/빽도 또는 낙을 결정합니다.
3. 물리 시뮬레이션 중 생성된 위치·회전 프레임을 브라우저로 전달합니다.
4. 브라우저는 그 프레임을 그대로 재생하며, **마지막에 윷을 중앙으로 옮기거나 회전시키지 않습니다.**
5. 옆면이나 끝으로 선 투척은 판정에 쓰지 않고 서버가 새로운 물리 투척을 시뮬레이션합니다. 12회 이내에 유효 투척이 없으면 오류를 반환하며, 해당 차례는 다시 던질 수 있습니다.

결과는 클라이언트가 만들어 보내지 않습니다. 무료/가상머니 방 모두 서버가 결과를 판정합니다.

## 반영/유지

- 반원 단면의 3D 윷, 평면(뒤)·곡면(앞) 구분, 특별 윷 빽도 유지
- 실제 착지 시 하나 이상의 윷 끝이 투척판을 벗어나면 낙
- 파워 게이지·게임판 이동·20초 제한·준비 버튼·팀전 잠금 유지
- 회원정보와 가상머니 저장 DB 코드는 수정하지 않음

## 배포

1. 압축을 풀고 GitHub 저장소의 같은 위치에 모든 파일을 교체합니다.
2. `throw-physics.mjs`와 `physics-sim-test.mjs`는 `server.js`와 같은 최상위 경로에 넣습니다. `public/yut3d.js`와 `package.json`, `public/index.html`도 반드시 갱신합니다.
3. Render의 Build Command가 `npm install`인지 확인합니다. 새로운 `cannon-es` 패키지가 설치되어야 합니다.
4. Render의 최신 배포가 Live로 표시되면 브라우저를 새로고침합니다.
5. Neon `DATABASE_URL`은 유지합니다.

## 검증 범위 및 한계

- 게임 규칙 자동 테스트 30개, 기존 3D 보조 검증, 파워 게이지 표시 검사, JavaScript 구문 검사는 통과했습니다.
- **새 서버 Cannon-ES 실제 물리 시뮬레이션과 WebGL 재생 통합 테스트는 현재 작업 환경에서 패키지 설치용 네트워크가 차단되어 실행하지 못했습니다.** 배포 후 첫 투척 테스트가 필수입니다.
- 렌더링/물리 결과에 오류가 나면 Render `Logs`와 브라우저 개발자 도구 `Console`을 확인해 주세요. 기존 게임을 안정적으로 운영 중이라면 GitHub를 별도 브랜치로 테스트하는 것을 권장합니다.
- 새로운 서버 판정 알고리즘은 과거 버전과 결과 분포가 다를 수 있습니다. 승률·밸런스는 충분한 표본 투척 후 조정해야 합니다.
