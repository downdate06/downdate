# 윷판 승부 v2.6 — 게임판에서 말 먼저 선택 + 3D 낙/착지 가시성 수정

## 달라진 조작
1. 던진 결과(모·윷·도 등)는 기존처럼 축적됩니다. 먼저 결과 버튼을 누를 필요가 없습니다.
2. 내 말을 먼저 누릅니다. 출발 전 말도 선택할 수 있습니다.
3. 선택한 말이 **현재 축적된 모든 결과**로 갈 수 있는 위치가 게임판에 표시됩니다. 게임판에는 결과 이름(도, 개, 걸, 윷, 모, 빽도), 업기/잡기/도착/완주 표시와 경로 점선이 나타납니다.
4. 목표 위치를 누르면 해당 결과만 소비됩니다. 남은 결과는 유지되므로 다음 말을 다시 선택할 수 있습니다.
5. 모퉁이에서는 바깥길 또는 지름길 중 표시된 위치를 선택할 수 있습니다.

## 윷 3D 표시 개선
- 물리 충돌과 회전 애니메이션 후 서버가 판정한 결과에 맞춰 네 윷의 착지를 화면 중앙에 배치합니다.
- 정상 결과에서는 네 윷 모두 투척판 안에 보이도록 위치를 고정합니다.
- 낙은 윷 한 개가 투척판 바깥에 남으며 화면에 빨간 '낙' 표시를 보여줍니다.
- 평평한 앞면(갈색 줄무늬)과 둥근 뒷면(밝은 목재)을 구분하고 아래에 앞면/뒷면 숫자를 표시합니다.
- 3D 물리 충돌이 *실제 서버 결과를 결정하는 것은 아닙니다*. 서버에서 확정한 결과에 맞춰 최종 3D 착지 상태를 연출합니다. 실제 착지 물리 기반 판정 구현은 추후 작업입니다.

## 규칙
- 윷/모로 상대 말을 잡았을 때 별도 '잡기' 추가 던지기를 주지 않습니다(윷/모 자체로 얻은 던지기는 이미 실행).
- 도/개/걸로 상대 말을 잡으면 한 번 더 던지고, 기존 결과는 보관합니다.
- 도착칸(오른쪽 아래)에 먼저 착지하며, 다음 양의 이동 결과가 나와야 완주합니다.
- 도 후 빽도 시 도착칸에 서도록 처리합니다. 빽도는 특정 표시가 있는 윷의 앞면 한 개가 나왔을 때 발생합니다.
- 개인전 2·3·4인, 4인 팀전, 로그인·Neon 저장 코드는 유지합니다.

## 배포
1. ZIP 압축을 풀어 **파일 내부**를 GitHub 저장소 최상위에 올립니다. `server.js`, `package.json`, `render.yaml`, `public/`이 저장소 루트에 있어야 합니다.
2. 기존 파일들을 덮어쓰고 Commit changes 합니다.
3. Render가 Live 상태가 되면 모바일에서는 사이트를 새로고침합니다.
4. 기존 Neon DATABASE_URL 설정은 변경하거나 삭제하지 마세요.
