# 윷판 승부 v2.4 — 누적 결과 완전 자유 선택

v2.3을 기반으로 누적된 윷 결과의 **사용 순서**와 **움직일 말 선택**을 자유롭게 조작하도록 화면을 개선했습니다.

## 사용 방법
1. 윷 던지기가 끝나면 게임판 바로 위에 모든 누적 윷 결과가 표시됩니다.
2. **모, 윷, 도 중 원하는 결과를 먼저 누릅니다.** 처음 결과가 자동 선택되지 않습니다.
3. 판 위 기존 말이나 플레이어 칸의 출발 대기 말 중 **원하는 말을 누릅니다.**
4. 게임판에서 반짝이는 도착 칸을 누르면 이동합니다.
5. 남은 결과를 다시 자유롭게 고르고, 새 말 또는 기존 말을 선택할 수 있습니다.
6. 상대 말을 잡으면 추가 투척하고 남은 결과를 보존합니다.

예시: 모 → 윷 → 도를 던졌더라도 도 → 모 → 윷 또는 윷 → 도 → 모 순서로 이동할 수 있습니다.

## 서버 업데이트
이 ZIP의 파일을 GitHub 저장소 루트에 동일한 경로로 업로드합니다. `public/` 안의 파일도 교체하고 Commit changes 후 Render가 Live가 되면 사이트를 새로고침합니다.

계정·게임머니 데이터는 Neon의 `DATABASE_URL`에 연결되어 있을 때만 서버 재배포를 넘어 유지됩니다. Render에서 `DATABASE_URL`을 삭제하거나 바꿀 필요는 없습니다.

## 검증
`node tests.js` 실행으로 기존 게임 로직 16개 + 자유 이동 순서 2개를 점검할 수 있습니다. 화면은 브라우저 수동 테스트가 추가로 필요합니다.
