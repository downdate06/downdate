# 윷판 승부 v2.7 — 영상 참고 / 원형 3D 투척판 / 말 우선 이동

## 핵심 변경
- 업로드한 두 MP4에서 직접 추출한 경기 장면을 참고하여 게임판 옆의 **원형 나무 투척판**을 새로 구현했습니다. 영상 그래픽을 복제하지 않고, 둥근 바닥판/나뭇결 링/조명/그림자로 독자적으로 제작했습니다.
- 4개 윷은 3D D자형 나무 몸체(둥근 등, 평평한 면)로 새로 모델링했습니다. 평평한 앞면은 어두운 갈색이며 홈이 있고, 둥근 등면은 밝은 색입니다. 한 개는 빽도 표식이 있습니다.
- 투척 시 중력·회전·윷끼리 충돌·충돌음 재생 후 착지 애니메이션이 이어집니다. **서버 판정에 맞춰 최종 위치·앞뒤 방향을 보정하는 연출**입니다. 실제 물리 엔진이 게임 결과를 판정하는 것은 아닙니다.
- 정상 결과는 4개 모두 원형 나무판 **안쪽에 안정적으로** 착지합니다. 낙은 1개가 **원 바깥**에 놓인 상태로 끝나고 큰 낙 메시지를 표시합니다. 브라우저 CDN 로드가 실패해도 공식 결과 문구가 멈추지 않도록 안전장치를 두었습니다.
- 누적 윷 결과 버튼을 먼저 선택하지 않습니다. **기존 말 또는 출발할 말 선택 → 게임판에 모든 결과별 이동 가능 도착칸 표시 → 목적지 및 결과 터치** 순서입니다. 각 후보 경로는 가느다란 점선으로 안내합니다.
- 사용자 지정 룰: 도·개·걸 잡기 때만 추가 던지기, 윷·모 잡기 때 보너스 투척 없음, 모퉁이 지름길 강제, 도착칸에 정지 후 다음 결과로 완주, 빽도, 윷/모 후 추가 투척과 결과 누적 및 사용 순서 자유 유지.
- 기존 2~4인 개인전, 4인 팀전, 로그인, 가상 게임머니, Neon `DATABASE_URL` 연동은 그대로 유지됩니다.

## Render / GitHub 업데이트
1. 이 ZIP을 압축 풀어 `game.js`, `server.js`, `package.json`, `render.yaml`, `public/` 등이 GitHub 저장소 **루트**에 오도록 업로드합니다.
2. 이전 파일을 덮어쓴 뒤 Commit changes.
3. Render의 최신 배포가 Live인지 확인하고 웹페이지에서 강력 새로고침(PC Ctrl+Shift+R, 모바일 사이트 데이터 새로고침)합니다.
4. Render 환경변수 `DATABASE_URL`은 그대로 유지합니다. 데이터베이스 비밀번호는 GitHub에 커밋하지 않습니다.

## 시험 권장 시나리오
- 두 기기에서 같은 방 입장 후 모→윷→도 누적, 서로 다른 순서로 각각 새 말과 기존 말 이동.
- 도·개·걸로 잡기 → 재투척; 윷·모로 잡기 → 추가 던지기 없음.
- 모퉁이에서 자동 지름길, 빽도, 도착칸에서 정지 후 다음 결과로 완주.
- 도/개/걸/윷/모 각각 정상 착지 4개 확인, 낙에서는 윷 1개가 원 밖인지 확인.
- 같은 아이디 재로그인 및 Render 재배포 후 잔액 확인(Neon 연결 시).

`npm install && npm test`로 게임 규칙 테스트를 수행할 수 있습니다. `npm start`로 로컬 서버를 실행합니다.

**검증 한계:** 규칙 자동 테스트 및 파일 구문 검사는 통과했지만, 현재 테스트 환경에서는 Chromium의 로컬 페이지 접속이 정책상 차단되어 3D WebGL의 실제 모바일 렌더링을 확인하지 못했습니다. 게임 방은 Render 무료 서버 재시작 시 보존되지 않습니다. 게임머니는 실물 화폐가 아니며 환전 기능은 없습니다.
