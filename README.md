# 윷판 승부 v3.9 — 투척 실패/과다 낙 긴급 수정

v3.8에서 발생한 **던지기 미동작** 및 **거의 모든 던지기가 낙으로 판정**되는 문제를 줄이기 위한 안정화 버전입니다.

## 변경사항

- `throw-physics.mjs`: 미설치/실패 가능성이 있던 Cannon 서버 충돌 시뮬레이션을 외부 물리 패키지에 의존하지 않는 서버 구름·충돌 근사 계산으로 대체했습니다.
- 서버가 네 윷의 낙하·회전·수평 충돌·바닥 반발·마찰·안정화를 계산하고 프레임을 브라우저에 전달합니다.
- 낙은 무작위 숫자가 아니라 **원형판 반경 밖으로 돌출된 윷의 최종 위치**로 결정합니다. 정상 결과는 실제 마지막 프레임의 평평한 면/둥근 면에서 계산합니다.
- 착지 후 윷을 가운데로 재배치하거나 결과에 맞춰 뒤집는 코드는 사용하지 않습니다.
- `package.json`의 서버 Cannon 의존성을 제거해 이전 투척 오류 가능성을 줄였습니다.
- 기존 2~4인 개인전, 20초 제한, 팀전 잠금, 로그인 및 Neon 데이터베이스 관련 파일은 유지합니다.

## 배포

1. ZIP을 풀고 GitHub 저장소의 기존 파일과 같은 경로에 교체합니다.
2. `throw-physics.mjs`와 `package.json`은 프로젝트 최상위 경로에 위치해야 합니다.
3. Render에서 Build Command `npm install`, Start Command `node server.js`를 유지합니다.
4. Render `Live` 후 무료 2인 방을 만들어 테스트해 보십시오. 가상머니를 걸기 전에 여러 번 시도하는 것이 좋습니다.

## 검증

- 기존 개인전 게임 규칙 30개, 파워 게이지/빽도 표시 검사, 게임 서버의 2인 웹소켓 연동 테스트를 통과했습니다.
- 서로 다른 파워를 섞어 240번 서버 투척 후 낙 비율, 최종 위치 안정성, 보여주는 네 면과 판정 비트 일치 여부를 검사합니다.
- 이 버전의 물리 계산은 **기하학적으로 정확한 강체 충돌 엔진의 완전 대체품은 아니며**, 안정성을 위해 단순화된 구름/충돌 근사 계산입니다. 실제 스마트폰의 WebGL 재생은 별도 확인이 필요합니다.
