# 윷판 승부 v3.6 — 중앙 경로 / 파워 게이지 / 착지 표시 수정

## 설치·배포

Render + GitHub 기존 프로젝트에 덮어쓰는 업데이트입니다. ZIP 압축을 풀어 저장소 최상위의 `game.js`, `server.js`, `package.json`, `tests.js` 등을 같은 위치에 교체하고, `public/` 폴더 내부의 새 파일들도 **하나도 빠뜨리지 않고** 교체해 주세요. 특히 이번에 추가된 `public/throw-logic.js`와 변경된 `public/yut3d.js`, `public/landing-physics.js`, `public/app.js`, `public/index.html`이 꼭 필요합니다.

GitHub에서 `Commit changes` 후 Render가 최신 커밋으로 배포되고 `Live`인 것을 확인하세요. 아이폰 Safari의 오래된 캐시가 남으면 탭을 닫고 게임 사이트를 다시 여세요. 로고 아래 `v3.6`이 보이면 이번 파일을 받고 있는 것입니다. Neon의 `DATABASE_URL`은 바꾸지 마세요.

## 이번 변경

- **파워 게이지 왕복**: 0→100→0을 누르는 동안 반복. 손을 놓는 그 순간의 값 사용(한쪽 1.4초). 화면에서 표시하는 힘이 실제 게임 승률을 조작하지는 않습니다.
- **빽도 앞뒤**: 판정 비트와 UI 표기를 한 계약으로 연결. 빽도는 앞·앞·앞·★뒤(평평한 진한 면)이고, 특수 윷은 4번째입니다.
- **중앙 분기**: 오른쪽 위에서 들어오면 **중앙을 지나 왼쪽 아래**로 직진, 왼쪽 위에서 들어오면 **오른쪽 아래**로 직진합니다. 정확히 중앙에 멈춘 뒤 다음 이동을 선택할 때만 꺾을 수 있습니다.
- **물리 연출과 최종 결과**: 초기 투척과 충돌에는 Cannon 물리 충돌체를 사용합니다. 이후 확정된 결과에 맞는 안전한 안착 자리(판 안)에 천천히 안정화시키며, 최종 앞뒷면이 위를 향하도록 자세를 맞춥니다. 낙은 하나가 판 밖에 위치합니다. 앞뒤 네 칸 표시는 **착지 완료 이후에만** 보여줍니다.
- **대기실·회원정보**: 기존 개인전, 준비, 20초 턴, 보유머니 표시, 나가기, Neon 저장 코드는 유지합니다.

## 기술적으로 정확한 설명

이 게임은 여전히 서버가 난수로 도·개·걸·윷·모·빽도·낙을 결정하는 **서버 판정 방식**입니다. 3D 충돌이 최종 결과를 생성하는 물리 기반 판정은 아닙니다. 이번 업데이트는 물리 중간 장면과 최종 판정의 시각적 혼란을 줄이고 **최종 확정된 3D 자세와 문자 결과를 동기화**한 것입니다. 화면에서 자연스러워 보이는지 최종 기기 검증은 별도로 필요합니다.

## 테스트

`npm test`로 게임 규칙·물리 충돌체·윷 앞뒤/게이지·서버 입장 테스트를 실행할 수 있습니다. `node timer-test.js`는 약 20초가 필요한 시간제한 테스트입니다.
