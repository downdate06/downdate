# 윷판 승부 v3.2 — 개인전 우선 버전

팀전 메뉴 및 서버 생성 요청을 비활성화했습니다. 팀전은 `개발 중`으로 표시됩니다.

개인전 2~4인, 이전 룰/3D/회원정보/가상 게임머니 시스템은 유지합니다. 게임머니 설계 변경은 아직 적용하지 않았습니다.

**중요:** 지금 코드의 가상 머니 정산은 출시 준비가 끝난 형태가 아닙니다. 서버 중단 환불, 여러 계정의 원자적 정산, 보유액 기반 방 제한 및 미션·배수는 별도 작업이 필요합니다. 테스트 목적 이외의 유료 운영에는 적합하지 않습니다.

현황 및 권장 설계는 `REVIEW.md`를 참고하십시오.

실행: `npm install` 후 `npm test`, `npm start`. 기존 Render에 배포할 때 Neon `DATABASE_URL`은 유지하십시오.
