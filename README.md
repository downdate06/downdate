# 윷판 승부 v2.9 — 준비/시작/참가비 + 늦은 결과 공개 + 물리 연출

## 변경 사항

- 방 생성 시 **자동 시작하지 않음**. 2~4인 개인전 또는 4인 팀전에서 각 참가자가 `준비하기`를 누릅니다.
- 전원이 접속하고 준비했을 때만 **방장(1P)이 `게임 시작` 버튼을 사용할 수 있습니다**.
- 가상 게임머니 참가비는 **방장이 게임 시작을 승인하는 순간** 서버에서 1회 차감합니다. 방 입장 또는 준비 버튼을 누르는 단계에서는 차감하지 않습니다.
- 종료 화면에 **`다시 한 판` / `나가기`** 버튼을 제공합니다. `다시 한 판`은 다시 준비하는 로비로 돌아갑니다. 종료 후 `나가기`는 방을 떠나 메인 화면으로 복귀합니다.
- 윷이 회전·충돌·굴러가는 장면을 약 **5초**로 늘렸습니다. 3D 물리 엔진의 충돌·구르기를 기존보다 길게 보여주고, 그 사이 **도·개·걸·윷·모/빽도/낙 판정 문구와 누적 결과/이동 경로를 숨깁니다.**
- 서버에서도 투척 후 5초 동안 후속 이동/재투척 명령을 거부하여 경기 결과가 선공개되지 않도록 제어합니다.
- iPhone / PC 화면에서 기존 말 선택 → 게임판 이동 경로 직접 터치, 결과 자유 사용, 도착/완주, 강제 지름길, 잡기/업기 규칙을 유지합니다.
- 결과는 서버가 난수로 결정하고 **마지막 착지 모습만 서버 판정에 맞춰 보정**합니다. 물리 충돌 자체로 결과를 정하는 기능은 아닙니다.

## 영상 검토

업로드된 8분 13초 강좌 영상과 26분 41초 실전 영상의 전체 개요 프레임 및 부분 연속 프레임 구간을 확인했습니다. 영상에서 **별도 원형 투척판, 던지기 직후 회전, 윷끼리 튕기고 구르다가 최종 안정 상태로 들어가는 과정**을 참고했습니다. 다만 두 영상의 모든 30fps 프레임과 음성을 완전히 검증하거나 넷마블과 동일한 물리 엔진을 재현한 것은 아닙니다.

## 업데이트 (기존 Render/Neon 유지)

1. 압축을 풀어 폴더 안의 모든 파일과 `public` 폴더 안 파일을 GitHub 저장소 **최상위** 동일한 경로에 업로드하여 교체합니다.
2. `Commit changes` 클릭. Render 자동 배포가 `Live`인지 확인합니다.
3. 아이폰에서 페이지를 새로고침하고 2명 방을 만들어 **입장→준비→방장 시작**을 확인합니다.
4. Render의 `DATABASE_URL`은 그대로 유지하세요. Neon의 회원정보와 게임머니는 기존 테이블을 사용합니다.

## 검증

- `npm test`: 규칙 테스트 25개 + 서버 WebSocket 통합 테스트 (2인 준비, 시작 전 금액 유지, 시작 후 1회 차감, 중복 시작 방지, 투척 중 재입력 제한, 나가기).
- 실제 아이폰 Safari의 WebGL·음향·모바일 터치 및 온라인 4인 대전 전체 시나리오는 자동 검증되지 않았습니다.
- 가상 머니는 **현금 교환이나 출금이 없는 게임 내 포인트**입니다. 현재 진행 중 게임이 서버 재시작·연결 중단 등으로 강제 종료될 경우 미완료 판의 환불/복구 시스템은 별도로 보완해야 합니다. 실제 금전 거래용으로 사용해서는 안 됩니다.
