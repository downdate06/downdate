# 윷판 승부 v2.1 — 윷 던지기·판 직접 선택 개선

## 변경점
- 기존 2·3·4인 개인전 / 4인 팀전 / 가상 게임머니 / 계정 기능 유지
- 말 클릭 → 윷 결과 선택 → 판에 표시되는 목적지(여기/잡기/완주)를 직접 터치하여 이동
- 대각선 갈림길은 가능한 목적지가 동시에 나타남
- 나무 재질 입체 윷 4개 및 물리 엔진 충돌·회전·낙하 애니메이션, 투척판
- 낙(약 5.5% 확률): 결과가 쌓이지 않고, 기존 보관 결과가 없으면 턴 종료. 윷/모로 쌓인 결과는 유지
- 충전 게이지 파워가 윷이 날아가는 애니메이션 세기에 반영됨. 게임 규칙 결과 자체는 서버 랜덤

## 주의
- 입체 윷 렌더링과 물리는 외부 jsDelivr CDN의 three.js와 cannon-es 모듈을 불러옵니다. CDN이 차단되면 3D가 표시되지 않을 수 있습니다.
- 투척 물리는 화면 연출이고, 윷 결과와 낙 판정은 부정행위를 막기 위해 서버에서 추첨합니다. 3D 윷의 실제 착지 방향/이탈 위치와 서버 판정이 항상 정확히 일치하도록 강제하는 기능은 아직 없습니다.
- 게임머니는 실제 현금 가치가 없는 가상 머니이며 현재 기존 v2 저장방식을 유지합니다. 영구 저장하려면 PostgreSQL 설정이 필요합니다.

## 배포 (기존 GitHub + Render)
1. 압축 해제한 폴더 **안의** 파일들을 GitHub 저장소의 동일 경로에 업로드해 덮어씁니다.
2. 추가 파일 `public/yut3d.js`도 업로드합니다.
3. `Commit changes` 후 Render의 자동 배포가 `Live`인지 확인합니다.
4. 아이폰/PC에서 새로고침(필요 시 캐시 삭제) 후 확인합니다.
