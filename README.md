# 윷판 승부 v4.2 — 룰북·베팅·벌금·미션 40종

## 주요 변경사항

1. **메인 화면 룰북:** 게임 규칙, 베팅·벌금·게임머니, 40종 미션 도감. 미션 도감 검색/유형 필터/2·3·4인 가능 조건 필터.
2. **게임머니:** 신규 가입 10,000머니. 보유 잔액이 2,000 미만이면 한국시간 기준 하루 1회 2,000까지 무료 보충. 무료방/1,000/5,000/10,000방.
3. **입장 시 예치:** 참가비와 동일한 벌금 예치금 보관. 유료방의 실제 최소 잔액은 2,000/10,000/20,000머니. 0머니방은 금전 정산 없음.
4. **잡기 벌금:** 업힌 말 개수별 ×1/2/4/8, 같은 턴 연속 잡기 회수별 ×1/2/4/6/8/10. 명목 벌금 = 참가비 10% × 업힌 말 배수 × 연속 잡기 배수. 한 번에 참가비 5배 상한, *실제 차감은 남은 벌금 예치금까지만*. 벌금은 승리자에게 지급하는 풀에 적립.
5. **경기 종료:** 참가비 총액 90%를 승자에게, 10%는 미션 점수 비율대로 분배. 달성 점수가 없으면 미션 풀도 승자에게. 벌금 풀 전체를 승자에게 지급하고 각자 미사용 벌금 예치금을 반환. 팀전은 이전처럼 잠금.
6. **미션:** 서버 관리 40종. 경기당 공통 3종 + 플레이어마다 다른 비밀 2종. 2·3·4인별 후보 제한, 중상급 미션 위주. 공통 선착순, 비밀 미션은 당사자만 볼 수 있음. PostgreSQL 사용 시 등장/달성 빈도를 익명 집계하며 미션당 표본 20회 이상일 때 달성률에 따라 다음 선정 가중치를 조정.
7. **빽도 세 곳 갈림길:** 중앙 23에서는 27/22, 왼쪽 아래 15에서는 14/25, 도착칸 30에서는 19/29 선택. 중앙 일반 전진은 오른쪽 아래로만 진행, 중앙 단순 통과는 직진.
8. **물리 판정:** 시각적으로 보이는 원형판 상단 반지름에 맞춰 서버의 낙 경계를 조정. 서버가 계산한 3D 투척 경로·면을 그대로 화면에 재생하는 기존 방식 유지. 정밀 강체 물리엔진으로의 완전 교체는 아닙니다.
9. **이탈과 복구:** 2인 진행 경기에서 플레이어가 나가면 남은 플레이어가 승리. 3·4인 진행 경기에서 이탈자가 생기면 경기를 취소하고 참가비·예치금을 전액 반환 (임시 안전 정책, 악용 방지 필요). PostgreSQL 연결 시 Render 재시작으로 사라진 미정산 경기의 예치금을 다음 시작 때 복구하도록 데이터베이스 거래 기록을 추가. 대기 중 방장 퇴장 시 먼저 들어온 남은 참가자에게 방장 위임.

## 설치

기존 GitHub 저장소에 압축을 푼 파일을 **모두 업로드**해 교체하고 커밋하세요. 특히 새 파일 `missions.js`, `economy.js`, `public/rules-ui.js`, `v42-test.js`를 함께 올려야 합니다.

Render는 Build Command `npm install`, Start Command `npm start`로 설정합니다. 기존 `DATABASE_URL` 비밀값은 GitHub 파일에 넣지 말고 Render Environment 설정을 유지하세요. DB에는 계정과 결제 회복 기록, 미션 집계 테이블이 처음 서버 실행 시 생성됩니다. 기존 계정 잔액은 초기화하지 않습니다.

**중요:** 진행 중인 경기는 서버 메모리에 있으며, 배포 시 방은 초기화됩니다. 유료 경기 잔액은 Neon 연결 시 다음 시작에서 예치금이 환불되도록 구현했습니다. 새로운 베팅과 정산을 사용하는 v4.2부터는 반드시 PostgreSQL 연결을 확인하세요. 기존 운영 중인 경기 도중의 배포는 피하는 편이 좋습니다.

## 현재 제한사항

- 3D 충돌은 근사 시뮬레이션입니다. 윷끼리 관통하거나 위아래 지지가 부자연스러운 일부 상황이 남아 있을 수 있습니다. 실제 iPhone/브라우저 렌더링은 별도 확인이 필요합니다.
- PostgreSQL 트랜잭션의 실제 Neon 환경 통합 실험은 이 환경에서 진행하지 못했습니다. 위 내용은 설계 및 로컬 검증이며, 유료방은 우선 무료 테스트 계정으로 작은 수의 게임을 검증하세요.
- 3·4인 경기 중 탈주하면 전액 환불되는 정책은 반복 악용될 수 있습니다. 향후 몰수/연결 복귀 정책을 설계해야 합니다.
- 일부 미션은 희귀하며 달성이 어려울 수 있습니다. 실측된 출현율과 달성률은 `/api/mission-stats`에서 확인할 수 있습니다.
- 게임머니는 현금 가치가 없으며 현금 환전, 현금 거래, 실물 재화 지급을 지원하지 않습니다.
