# 윷판 승부 v2.3 — 표시/업기/잡기 개선

## 이번 수정 사항
- 이전 결과를 말 이동 때마다 3D 윷으로 다시 던지던 문제 해결: 서버 `throwNo` 기준으로 한 번만 재생
- 3D 윷 결과를 서버에서 결정한 네 면(`bits`)과 일치하도록 착지 화면을 보정하고, 평/등 4개의 명확한 판정 표시 추가
- 모바일 투척판 높이를 225px에서 136px로 축소해 게임판과 결과가 잘 보이도록 정리
- 이동 가능 목적지에 `업기` / `잡기` / `이동` / `완주` 표시
- 남은 윷 결과 개수와 각 결과 선택 버튼을 명확하게 표시
- 서버 핵심 이동 규칙 검증: 모·도 축적 → 도로 업기 → 모로 동시 이동, 모·도 축적 → 도로 잡기 → 다시 던지기 → 남은 결과 유지

## 주의
서버에서 윷 결과를 공정하게 결정하며 3D 장면은 그 결과에 맞춰 착지를 보정합니다. **물리 시뮬레이션에서 자동으로 점수를 판독하는 버전은 아닙니다.** 네 개의 윷 면 표시는 실제 판정과 일치하도록 설계했습니다. 낙은 별도 무효 판정입니다.

기존 `DATABASE_URL` 환경 변수는 바꾸지 마십시오. 데이터베이스를 아직 연결하지 않았다면 회원정보는 Render 재시작 시 사라질 수 있습니다.

## 배포
ZIP 압축을 푼 뒤 기존 GitHub 저장소의 **같은 경로**에 변경된 파일을 덮어 업로드하십시오. `server.js`, `game.js`, `auth.js`, `package.json`, `render.yaml`, `public/` 폴더 등 최상위 구조를 유지해야 합니다. `Commit changes` 후 Render의 새 배포가 Live인지 확인하십시오. 게임방은 재배포 때 초기화됩니다.
